🚀 YT-Neo — Neo-Brutalist YouTube Clone

YT-Neo is a full-stack YouTube-inspired platform built with a Neo-Brutalist design approach, combining bold visuals with powerful backend functionality. It delivers video streaming, live broadcasting, and real-time user interactions in a visually striking and modern interface.

Unlike traditional clones, YT-Neo focuses not only on functionality but also on design identity, using sharp contrasts, strong typography, and expressive UI elements.

🎨 Design Philosophy
🟥 Neo-Brutalism UI (bold colors, sharp edges, high contrast)
⚡ Minimal yet expressive layout
🎯 Focus on usability + visual impact
🎥 Inspired by modern web + gaming UI aesthetics
✨ Features
🎥 Video Upload & Streaming
🔴 Live Streaming (LiveKit)
💬 Real-time Comments (Socket.io)
👤 Authentication (JWT + Cookies)
❤️ Likes, Subscriptions, Playlists
🔍 Search & Trending
☁️ Cloudinary Media Storage
⚡ Redis + BullMQ for performance
🛠️ Tech Stack
🎨 Frontend
React (Vite)
Tailwind CSS (Neo-Brutalist styling)
Framer Motion
LiveKit Client
Socket.io Client
⚙️ Backend
Node.js + Express
MongoDB
Redis + BullMQ
LiveKit Server SDK
JWT Auth + Cookies
🔥 What makes it unique
🎨 Strong Neo-Brutalist design system
🔴 Integrated live streaming + real-time features
⚡ Scalable backend with queues + caching
🧠 Clean full-stack architecture
